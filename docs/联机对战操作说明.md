# 联机对战操作说明

## 快速开始

### 第一步：启动服务器（主机电脑）

**方式一：双击启动（推荐）**

双击项目根目录下的 `start-server.bat`，会自动显示本机 IP 地址和端口。

**方式二：命令行启动**

```bash
cd 商周大战
npm install    # 首次运行需要安装依赖
node server.js
```

启动后会显示类似信息：

```
===========================================
  商周大战 - 局域网联机服务器
===========================================
  本机 IP: 192.168.2.21
  端口: 8080
-------------------------------------------
  请将以下地址告诉对手:
  192.168.2.21:8080
===========================================

等待玩家连接...
```

**记下显示的 IP 地址，告诉对手。**

---

### 第二步：玩家连接

**两位玩家都需要操作：**

1. 打开游戏（浏览器打开 `index.html` 或 `codes/商周大战.html`）
2. 在右侧面板找到"对手"下拉框
3. 选择"联机对战"
4. 在出现的联机面板中，输入服务器地址（如 `192.168.2.21:8080`）
5. 点击"连接"按钮
6. 显示"已连接服务器"表示连接成功

---

### 第三步：创建/加入房间

**房主（先手）：**

1. 点击"创建房间"按钮
2. 获得 6 位房间号（如 `123456`）
3. 将房间号告诉对手
4. 等待对手加入...

**对手（后手）：**

1. 输入房主给的 6 位房间号
2. 点击"加入房间"按钮
3. 游戏自动开始

---

### 第四步：开始游戏

- **房主执白方（先手）**
- **对手执黑方（后手）**
- 白方先行棋

界面提示会显示当前轮到谁行棋。

---

## 游戏操作

### 行棋

1. 轮到你时，点击己方棋子（会高亮显示可走位置）
2. 点击目标位置完成落子
3. 等待对手行棋

**注意：不是你的回合时，点击棋盘无效。**

### 悔棋

1. 点击"悔棋"按钮
2. 对手会收到悔棋请求弹窗
3. 对手同意后，双方同步回退一步
4. 对手拒绝则悔棋失败

**联机模式下悔棋需要对方同意，不能单方面悔棋。**

### 查看规则

点击"规则"按钮可展开规则说明。

## 常见问题

### Q: 连接失败怎么办？

**检查以下几点：**

1. **服务器是否启动？** 确认主机电脑的服务器窗口显示"等待玩家连接..."
2. **IP 地址是否正确？** 在主机电脑上运行 `ipconfig` 确认 IP
3. **是否在同一局域网？** 两台电脑需连接同一个 WiFi 或路由器
4. **防火墙是否放行？** 主机电脑需要放行 8080 端口

**放行防火墙方法（主机电脑）：**

以管理员身份运行 CMD，执行：
```bash
netsh advfirewall firewall add rule name="商周大战联机" dir=in action=allow protocol=TCP localport=8080
```

### Q: 显示"房间不存在"？

- 确认房间号输入正确（6 位数字）
- 确认房主已点击"创建房间"
- 确认房间未满（最多 2 人）

### Q: 显示"房间已满"？

- 该房间已有 2 位玩家
- 请房主重新创建房间

### Q: 对手断线了怎么办？

- 界面会提示"对手已离开房间"
- 需要重新创建房间开始新局

### Q: 可以在不同网络（外网）联机吗？

当前设计仅支持局域网。如需外网联机，需要：
- 路由器端口转发
- 或使用内网穿透工具（如 frp、ngrok）

## 界面说明

### 联机面板

```
┌─────────────────────────────────────────┐
│ 服务器地址: [192.168.2.21:8080] [连接]  │
│ 房间号:     [123456          ] [创建] [加入] │
│ ┌─────────────────────────────────────┐ │
│ │           已连接服务器              │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

### 状态提示

| 提示 | 含义 |
|------|------|
| 未连接 | 未连接服务器 |
| 连接中... | 正在连接服务器 |
| 已连接服务器 | 连接成功，可以创建/加入房间 |
| 房间 123456，等待对手加入... | 房间已创建，等待对手 |
| 对手已加入！你执白方（先手） | 游戏开始 |
| 轮到你行棋。 | 你的回合 |
| 等待对手行棋... | 对手回合 |
| 对方请求悔棋，是否同意？ | 悔棋协商弹窗 |
| 对手已离开 | 对手断线 |
| 连接失败，请检查地址 | 地址错误或服务器未启动 |

## 测试方法

如果想先测试联机功能，可以用同一台电脑开两个浏览器标签页：

1. 启动服务器：`node server.js`
2. 打开两个浏览器标签页，都访问游戏页面
3. 标签页 A：选择联机 → 连接 → 创建房间
4. 标签页 B：选择联机 → 连接 → 输入房间号 → 加入
5. 开始对弈测试

## 技术信息

- 通信协议：WebSocket（ws://）
- 默认端口：8080
- 消息格式：JSON
- 依赖：ws 库（Node.js）
