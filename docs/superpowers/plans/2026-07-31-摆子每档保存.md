# 摆子每档独立保存 · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把摆子面板从单一 localStorage 自定义档，改造成**每个档位都能就地编辑、单独保存到 `codes/layouts/{preset}.json`**。"自定义"作为四档之一（`custom.json`）与其他内置档同源处理；不再读写 `localStorage`。

**Architecture:** 在单 HTML 应用扩展。所有改动落在 `codes/商周大战.html`（源）；`index.html` 由 `sync-index.bat` 同步。新增工具函数 `downloadLayoutAsJson(presetKey)` 通过浏览器下载覆盖 JSON。`loadPresetLayouts` 拉取时多挂 `custom.json` 一档，路径与 `small/battle/final` 同。验证沿用 `.claude/verify-skin.js` / `.claude/verify-layout.js` 的 `vm` sandbox 模式，新增 `.claude/verify-setup-save.js`。

**Tech Stack:** Vanilla HTML/CSS/JS（无构建、无 npm），Node `vm` 模块跑 stub DOM 做验证，`sync-index.bat`（cmd）做 HTML 同步。

## Global Constraints

- 源文件 = `codes/商周大战.html`；`index.html` 由 `sync-index.bat` 同步，最后一个任务统一跑。
- 坐标系统：`COL_LETTERS = "ABCDEFGHJKLMNOPQRST"`（跳 I），列字母 = `COL_LETTERS[col]`，行号显示 = `row + 1`。
- 布局条目格式：`[阵营, 兵种, 列col, 行row]`，兵种 ∈ `{king, soldier, horse}`。
- 棋谱 / 布局 JSON schema：`{game:"商周大战", preset, moves?:[], layout?:[[side,type,col,row]]}`。
- 验证脚本沿用 `.claude/verify-skin.js` / `.claude/verify-layout.js` 的 `vm` sandbox + stub DOM + `ok()/fails` + `process.exit` 模式。

- YAGNI：不主动迁移老 `localStorage` 自定义数据到 `custom.json`；不加新建入口；不动导出 / 导入按钮；不动 PRESETS；不动皮肤与移动端。

// 文件名 = presetKey + ".json"，用户须手动覆盖到 codes/layouts/{presetKey}.json
function downloadLayoutAsJson(presetKey) {
  const data = {
    game: "商周大战",
    preset: presetKey,
    moves: [],
    layout: pieces.map(p => [p.side, p.type, p.col, p.row]),
  };
  const blob = new Blob([JSON.stringify(data, null, 2)], { type: "application/json" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
